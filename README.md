# 🟢 Página Informativa - Nojinho (Divertida Mente 2)

**Este projeto é uma página web simples e responsiva desenvolvida para apresentar informações sobre a personagem Nojinho, da animação Divertida Mente 2.** O site destaca o papel da emoção em proteger a protagonista Riley, apresentando um design temático baseado na identidade visual da personagem.

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica do conteúdo da página.
*   **CSS3:** Estilização personalizada, utilizando Flexbox para o alinhamento dos elementos de navegação.
*   **CodePen:** Plataforma online utilizada para o desenvolvimento e hospedagem do código.

## 💻 Estrutura do Código

*   `index.html`: Contém a estrutura da barra de navegação (`<nav>`) com os links (Início, Sobre, Personagem) e a seção principal com a imagem e o texto descritivo.
*   `style.css`: Define as propriedades visuais, como a remoção de margens padrão do `body`, a cor de fundo verde temática para o menu e a organização da lista em modo flexível (`display: flex`).
